To add an iPad, connect it to the school Wi-Fi, open portal.csjax.org/kiosk in Safari and give it a name — no staff sign-in needed. The kiosk only works on the school network. Tap Share → Add to Home Screen for full-screen mode. Turning an iPad off here stops it from working until it's set up again.

Staff & RulesData UploadAlerts
Data Upload — Daily File from the SFTP Server

Upload the student & parent CSV to the uploads folder on the SFTP server (141.148.36.44, login ccsftp). On school days the portal checks at 10:00 AM and 5:00 PM for the student & parent file and at 11:30 AM for the daily attendance file (and keeps checking every 5 minutes for half an hour in case a file is late), imports the newest of each, and moves them to processed.
