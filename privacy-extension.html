Cornerstone Portal Dismissal Board (Chrome extension)
Published by Cornerstone of Jacksonville, Inc. (Cornerstone Christian School) · Effective November 4, 2026

This extension is an internal tool for Cornerstone Christian School teachers and classroom Chromebooks. It is installed by the school through Google Admin and is not intended for the general public.

What it does

  • On school days (Monday–Friday) it opens the school's dismissal board page, portal.csjax.org/classroom, full-screen at 2:35 PM and closes it at 3:30 PM (New York time).
  • The teacher picks their class once; the extension remembers that choice for future launches.
  • The teacher can tap “Close board” to close it for the rest of the day, or “Change class” to pick a different class.

Data collected

  • None. The extension does not collect, read, transmit, or sell any personal information, browsing history, or website content.
  • Stored in Chrome: the teacher's selected class (for example charles-brand), saved with Chrome sync so it follows the teacher's school Google account, and today's date if the board was closed (so it stays closed that day). Optional settings may be set by the school's IT administrator.
  • Website access: it runs only on portal.csjax.org/classroom, solely to make the “Close board” button work and to remember the selected class.

The dismissal board itself

The board shows student names and how each student goes home today (car rider, bus number, after-school care, walker). It is part of the school's Cornerstone Portal, can be viewed only on the school's campus network, and is handled as an education record under the school's FERPA obligations. The extension only opens the page; it does not read or store what the board shows.

Changes

If these practices change, this page will be updated and the effective date above will change.
